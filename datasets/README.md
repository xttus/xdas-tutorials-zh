# 数据集与获取入口

这里只整理用途、来源与获取方式，不镜像几 GB 原始记录，不把“可下载”当作可任意重新分发。

## 当前教程使用的数据

| 资源 | 内容与用途 | 来源 |
| --- | --- | --- |
| Xdas Toy DAS Datasets | POST、ABYSS 实验在智利中部 GTD 通信光缆的示例记录；用于文件组织、信号处理和坐标练习 | [Zenodo 11212055](https://doi.org/10.5281/zenodo.11212055) |
| `ntp_sync` | 约 2 分钟、有计时问题的样本 | 同上；教程 4 |
| `gps_multiacq` | 约 6 分钟、采集参数两次变化 | 同上；教程 1 |
| `gps_multicable` | 三条光缆约 10 分钟同步记录，可见区域地震 | 同上；教程 1 起主流程 |
| 光缆几何 CSV | 将沿纤位置关联到经纬度 | 上游 `install.py` 的几何准备步骤 |
| 台站波形与元数据 | miniSEED、StationXML；传统台站拾取及关联 | 上游 `install.py` 的 EarthScope 查询步骤 |
| Marot 2014 速度模型 | 深度、P/S 速度；关联定位的外部输入 | 教程 6 说明及 [Zenodo 12723613](https://zenodo.org/records/12723613) |

Zenodo 页面给出 `data.zip` 的 MD5 `6423a640378f39370f8350b54cd7b505`；请以实际记录的文件版本及其校验值为准。不同工具可能分别显示十进制 GB 与二进制 GiB，数字略有差异不代表缺数据。主数据下载成功也不代表台站、几何和其他外部步骤全部完成。

## 如何使用已有数据

见[本地数据管理](../guides/data-management.md)。不要为了汉化另复制一套原始数据；可以直接把中文 Notebook 放入已有可用项目。

## 后续增加数据集的统一记录项

名称与 DOI；提供者；许可；测量物理量与单位；采样率、标距和通道间距；时间和空间范围；文件格式与体量；几何和计时质量；是否有标签、标签来源和可靠性；适合与不适合的任务；下载与校验方法。

目前不把未经实测的外部数据列成“可直接复现”。有新数据时先写一页数据卡，再添加教程。
