# 术语表：结合语境，而非逐词替换

| 原文 | 建议中文 | 语境说明 |
| --- | --- | --- |
| channel | 通道 | 沿纤采样位置；台站三分量中的 channel 需另行说明 |
| distance | 沿纤距离或位置 | 坐标，不是波形测量幅度 |
| gauge length | 标距 | 不能与通道间距、独立分辨率混为一谈 |
| coiled fibre | 盘纤 | 光纤盘绕，沿纤距离不再一一对应地理推进距离 |
| neighbor | 相邻通道、邻近采样点或相邻数据块 | 按算法对象选词，不默认译成“邻居” |
| missing neighbors | 缺少所需的邻近数据或上下文 | 不一定是数量不足，可能是边界外数据未提供 |
| resampling / downsampling | 重采样／降采样 | 重采样也可以提高采样密度 |
| picking / picks | 震相拾取／候选到时 | 不等于事件分类或事件数 |
| association | 到时关联 | 寻找同一事件的共同解释 |
| chunk | 数据块 | 计算块不一定与原始文件边界相同 |
| atom | 处理单元 | Xdas 的处理抽象，不是物理原子 |
| pipeline | 处理流程或流水线 | 在代码里常只是用户命名的变量，可包含不同步骤 |
| state | 状态 | 影响后续块计算的内部记忆，不等于输出波形 |

## `...`、`>>`、`pipeline`、`.process()` 分别是什么

| 写法 | 本教程语境中的作用 |
| --- | --- |
| `...` | 在支持该约定的 Xdas 函数中，表示此时先构建处理单元，数据以后传入；不是任意 Python 函数都支持 |
| `>>` | 在相应对象支持时连接处理步骤，不是读取数据或立即完成全部计算 |
| `pipeline` | 保存某套步骤的普通变量名；具体流程由赋值内容决定，并非始终“滤波→取绝对值” |
| `pipeline(da)` | 对给定数据调用这套流程 |
| `pipeline.process(...)` | 组织从数据源读取、执行与输出的过程，参数依版本及数据源而定 |
| 分块 | 一种执行数据的方式，不是某一个函数名称，也不是每块都应重置流程 |

这些概念先分开理解，再看教程 3 的实际代码。不要把不同 Xdas 版本的 API 混抄到同一个环境。
