# 数据怎样安置

## 仓库与本地数据分开管理

本系列默认在 `tutorials/xdas/` 中运行。该目录下：

| 路径 | 用途 | 是否提交 Git |
| --- | --- | --- |
| `*_zh.ipynb`、环境文件 | 教程与可追溯环境说明 | 是 |
| `data/` | 原始数据、台站、几何与速度模型 | 默认否；入口与来源写进文档 |
| `outputs/` | 自己运行产生的虚拟数据集、拾取、事件表和回放包 | 否 |
| `.venv/` | 本地虚拟环境 | 否 |
| `.local-cache/` | 可选的本地缓存 | 否 |

不必把已有几 GB 数据复制一遍来配合新目录。已有环境可以直接复制中文 Notebook 过去运行。进阶使用者可通过配置或链接共享数据，但必须保证相对路径和虚拟数据集引用仍有效。

## 三个原则

1. 原始数据只读保留，修改或修复产生新文件，并记录方法。
2. 中间结果按复用价值保存，不默认保存每一步全量数组。
3. 可复现不仅需要输出，还需要输入清单、版本、参数和运行日志。

虚拟 NetCDF 可能引用原 HDF5 的位置。移动目录后，即使 `.nc` 文件还在，也可能无法读取原波形。不要仅凭虚拟文件大小判断数据是否完整归档。

## 备份与清理

教程的目录准备优先使用改名备份，而非无提示递归删除。备份仍占磁盘，重复运行会累积；手工检查确切目录内容后再决定删除。不清楚某目录用途时先不要动。

检查空间时分别看：原始压缩包、解压数据、回放副本、中间结果、虚拟环境、uv 缓存、模型缓存和系统临时目录。Notebook 内核也可能保留数组占用内存，但内存占用与磁盘占用不是同一件事。

Git 忽略规则只防止新文件被加入版本控制；不能自动移除已经提交的大文件，也不是备份或数据安全机制。
