# 常见问题：先找原因，再修改

提交报错时请附完整 traceback、触发代码、本地解释器、Xdas 版本和工作目录。截图可辅助，但复制文本更便于判断。

| 现象 | 先检查 | 建议处理 |
| --- | --- | --- |
| `No module named 'xdas'` | `sys.executable` 和 `xdas.__file__` | 选择已有项目环境，不要先在另一个 Python 里盲装 |
| `prepare_output_directory` 未定义 | 教程 7 前部辅助函数单元格是否运行成功 | 先运行定义；重启内核后需重做 |
| 行末出现 `)==`，提示 SyntaxError | 对照仓库代码 | 删除意外字符；不要据此改动数据或依赖 |
| 找不到 `outputs/event.nc` | 工作目录及教程 2 的保存步骤 | 从来源生成；不要创建空文件 |
| 缺 `latitude`、`longitude` | 文件实际坐标和教程 4 的几何准备 | 经纬度不会因 CSV 文件存在就自动附加到数组 |
| `marot2014.csv` 不存在 | 教程 6 速度模型准备部分 | 按该节获取或准备，核对列名和单位 |
| EarthScope 无 station service | 完整服务错误、网络、安装脚本版本 | DAS 数据可能已解压成功；台站下载单独排查，不必重下全部数据 |
| 内核重启或退出 | 内存、外部库异常、终端日志 | 先缩小选区，记录可重复触发步骤；不是单凭日志就确定原因 |
| 流处理一直 `0B` | 是否收到包、发布方式、源是否正常、线程是否异常 | 中断并检查；0B 不代表波形为零，也不是完成标志 |
| 图片不可见 | 是否为完整 `.ipynb`、附件是否保留、Markdown 是否渲染 | 本包检查附件引用；不要把原始 Markdown 源当成已渲染页面 |

## 教程 7 的特殊说明

本中文版本包含 `prepare_output_directory` 和非 Linux 回放用 `.ready` 标记协议。它们必须与对应的 `acquire`、数据源代码配套使用，不能只复制其中一格到英文原版。

`until=da['time'].values[-1]` 告诉流程本次回放的数据终点。它不是“运行多少秒”，也不是电脑当前时间。目标包一直不到达时，`until` 不会自行唤醒一个阻塞的读取器。

终端中 Ctrl-C 或 Notebook 中断可尝试停止任务；是否完整退出还取决于等待和线程实现。确认后台任务停止后再运行新一轮，必要时重启内核。

## 下载与代理

先用只读命令查看配置和服务是否运行，避免公开包含敏感信息的代理输出。不要把某次临时代理或个人路径写成全体用户必须采用的配置；不要关闭 TLS 验证来解决下载失败。
